AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉이 발생하는 특정 AMI 조합

클라우드/인프라 엣지케이스 / Cloudflare 캐시 무효화 지연

### 검색 의도 대응

1. **실패 원인**: CPU 크레딧 소진과 커널 패닉 발생으로 인한 서비스 중단 시간 및 클라이언트의 불편도.
2. **비교 기준**: 이 AMI 조합을 사용했을 때와 다른 AMI 조합을 사용했을 때의 비교.

### 구체성 원칙

- 특정 AMI 조합: ami-0e1a465623b8f7c12
- CPU 크레딧 소진 시간: 3분 전
- 오류 코드: AWS Error Code: TooManyRequests
- 클라우드 서비스 장애 발생 시 지연 이유: DNS 문제

### 실제 사례 서술

새벽 3시에 울린 페이저는 새롭게 구축한 웹사이트가 Cloudflare 캐시 무효화를 일으키는 문제가 있었음을 의미했습니다. 그러나 이 문제의 진짜 원인은 AWS Lightsail 인스턴스에서 CPU 크레딧 소진이 발생했을 때 바로 커널 패닉 현상이 발생하여 서비스 중단 시간과 클라이언트 불편도가 컸습니다.

#### 구체적 맥락

- **CPU 크레딧**: AWS Lightsail 인스턴스의 프리미엄 CPU 유동성을 관리하기 위한 자원입니다. 예를 들어, 특정 AMI 조합에서 CPU 크레딧 소진은 해당 AMI 조합의 부하가 너무 높아 전체 CPU 리소스에 도달함으로써 발생합니다.
- **커널 패닉**: AWS Lightsail 인스턴스가 커널을 통해 데이터 처리를 실행할 때 특정 오류나 에러가 발생하면, 모든 프로세싱 작업이 중단되는 현상입니다. 이 경우, CPU 크레딧 소진과 함께 커널 패닉은 서비스 중단 시간과 클라이언트 불편도를 증폭시킵니다.
- **AMI 조합**: 특정 AMI 조합은 사용하려는 서비스와 연관된 부품 및 설정을 포함합니다. 이 경우, ami-0e1a465623b8f7c12 AMI 조합이 문제를 일으키면, 다른 AMI 조합으로 교체하면 문제가 해결될 수 있습니다.

#### 관찰 포인트

- **CPU 크레딧 소진 발생 시각**: CPU 크레딧 소진은 3분 전에 발생하였습니다. 이는 AWS Lightsail 인스턴스가 부하를 초과하여 전체 CPU 리소스를 사용했음을 의미합니다.
- **오류 코드 확인**: 오류 코드는 AWS Error Code: TooManyRequests로, 클라우드 서비스 장애를 일으킨 문제의 유형을 나타냅니다. 이 경우, AWS Lightsail 인스턴스에서 CPU 크레딧 소진이 발생하여 부하가 초과되어 커널 패닉 현상이 발생하였습니다.
- **클라이언트 불편도**: 이 AMI 조합으로 인해 서비스 중단 시간이 길어졌으며, 클라이언트의 불편도 또한 크게 증가했습니다.

### 결론

CPU 크레딧 소진과 커널 패닉 현상은 AWS Lightsail 인스턴스에서 발생할 수 있는 매우 중요한 문제입니다. 이를 방지하기 위해선 AMI 조합을 변경하거나, 사용하려는 서비스에 더 적합한 리소스를 사용하도록 설정해야 합니다.
